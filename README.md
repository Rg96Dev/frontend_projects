
# Gulp uma ferramenta de automação de tarefas

## Neste exercício, foram propostos três tópicos para entrega

1.Criar um arquivo Gulpfile que deverá executar as tarefas:
* compilação do SASS;
* compressão de imagens disponibilizadas no Material de apoio;
* compressão de código JavaScript.



## Resumo

Realizei a instalação do Gulp de forma global e como dependência do projeto. Configurei o Gulp criando arquivos .gitignore para ocultar a pasta gerada pela implementação do Node.js no projeto, tornando-o mais leve para o deploy.

Trabalhei com o conceito de automação de tarefas, criando-as no Gulp utilizando funções. Dessa forma, compreendi o propósito da automação de tarefas com o Gulp no desenvolvimento Front-End.
