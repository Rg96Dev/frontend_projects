
# LESS (Leaner Style Sheets) a extensão da linguagem CSS

## Neste exercício, refatorei o arquivo CSS utilizando a ferramenta LESS.

## Resumo

Realizei a configuração do LESS em um projeto, incluindo a instalação de suas dependências. Utilizei variáveis para armazenar cores e valores de propriedades CSS. Apliquei o conceito de “escaping” no LESS e organizei o código incluindo mapas para agrupar valores relacionados, definindo propriedades e valores dentro deles.
